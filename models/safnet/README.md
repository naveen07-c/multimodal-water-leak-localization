# Model 3: SAFNet

This directory will contain the implementation of the Parameter-free Star-shaped Attention Fusion Network (SAFNet) based on the paper (`sensors-26-04451.pdf`).

## Pipeline
1. Data collection
2. Data cleaning/EDA
3. Split & preprocessing (1D Acoustic Emission Data)
4. Baseline
5. Model design (TPE + PLSA + MS-GAF)
6. Training
7. Tuning
8. Evaluation
9. Robustness testing
