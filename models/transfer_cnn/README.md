# Model 2: IoT-Based Transfer Learning CNN

This directory will contain the implementation of the IoT-based leak detection system using Transfer Learning and a Convolutional Neural Network (CNN) based on the paper (`main base paper.pdf`).

## Pipeline
1. Data collection
2. Data cleaning/EDA
3. Split & preprocessing (Mel-spectrograms)
4. Baseline
5. Model design (CNN with Transfer Learning)
6. Training
7. Tuning
8. Evaluation
9. Robustness testing
